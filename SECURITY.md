# Security policy

Please report security issues in Measure privately. Do not open a public issue.

Use [Report a vulnerability](https://github.com/ramon427/measure-releases/security/advisories/new)
on this repository's Security tab. Include the app version, your operating
system, and the steps needed to reproduce the issue.

Do not include passwords, tokens, or other people's data in your report.

Only the latest release gets security fixes.
